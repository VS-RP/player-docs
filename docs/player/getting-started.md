# Первые шаги на VS:RP

## Регистрация и вход

При первом подключении придумайте пароль для аккаунта — он будет привязан к имени персонажа (`Имя_Фамилия`). При повторном входе введите тот же пароль.

Если вы хотите защитить аккаунт, включите двухфакторную аутентификацию (2FA) через меню настроек — при входе потребуется код из приложения-аутентификатора (Google Authenticator, Authy и т.п.).

## Создание персонажа

Имя персонажа — это ваш «паспорт»: оно отображается над головой и в документах. После создания вы получите ID-карту в инвентарь — берегите её, она нужна для проверки личности.

## Первые действия

1. **Главное меню** — `/mm` или `/menu`. Быстрый доступ к статистике, инвентарю, квестам, фракции, бизнесу, бирже.
2. **Список базовых команд** — `/cmds`.
3. **Инвентарь** — `/inv`. Там уже лежит ID-карта.
4. **Статистика персонажа** — `/stats`: уровень, опыт, деньги, фракция.

## Навигация по городу

```
/gps
```

GPS откроет меню с категориями: больницы, полицейские участки, магазины, базы организаций, аренда транспорта и т.д. Выберите место — на карту ляжет маршрут.

Для поиска конкретного дома:
```
/house <номер>
```

## Деньги на старте

Стартовый капитал у новых игроков небольшой. Заработать можно:
- Работой в государственных службах (курьер `/courier`, водитель автобуса/трамвая/поезда через работы у зданий)
- Квестами — `/quest`
- Торговлей на биржевом рынке — `/stocks`, `/portfolio`
- Службой во фракции — зарплата по рангу (payday раз в час)
- Своим бизнесом, фермой, сбором грибов и кладов

## Сытость

Следите за сытостью — `/satiety`. При достижении нуля персонаж начинает терять здоровье. Еду покупают в магазинах и заведениях питания или собирают на фермах. Использование предметов еды — из инвентаря (`/inv` → выбрать предмет → «Использовать») или командой `/eat <тип>`.

## Смерть и возрождение

После смерти персонаж **всегда** попадает в больницу: там его осматривают, списывают часть наличных и восстанавливают здоровье. Это единственный путь возрождения — выбирать дом или другое место на момент смерти нельзя.

Выбор точки появления доступен только при **входе в игру**: после логина открывается диалог со списком доступных мест (свои дома и апартаменты, арендованные мотели, фракционная база, точка выхода). Повторно вызвать этот диалог на следующий спавн — команда `/spawnchange`.

## Полезные команды для начинающих

| Команда | Что делает |
|---------|-----------|
| `/mm` | Главное меню |
| `/cmds` | Список базовых команд |
| `/gps` | Навигация по городу |
| `/inv` | Инвентарь |
| `/stats` | Характеристики персонажа |
| `/id <игрок>` | Информация об игроке |
| `/satiety` | Уровень сытости |
| `/quest` | Журнал заданий |
| `/ask <вопрос>` | Задать вопрос администрации |
| `/report <игрок> <причина>` | Пожаловаться на игрока |
