# Ролевая игра

## Основы RP

VS:RP — ролевой сервер. Ты играешь роль персонажа, а не просто управляешь аватаром. Разделяй то, что знает твой персонаж (IC — In Character), и то, что знаешь ты как игрок (OOC — Out of Character).

---

## Чат

Просто текст в чат — это речь персонажа. Её слышат в радиусе 30 метров, громкость убывает с расстоянием, над головой появляется «пузырь» с репликой.

| Команда | Что делает |
|---------|------------|
| `/s <текст>` | Крик: слышен в радиусе 60 м., играет анимация крика |
| `/b <текст>` | OOC-чат (технические вопросы, не по роли) |
| `/ask <вопрос>` | Отправить вопрос администрации онлайн |
| `/tl <текст>` | Прогнать латиницу через транслит и отправить в чат |
| `/smileinfo` | Список текстовых смайлов и эмоций, распознаваемых в чате |

Если напечатать только смайл из списка, он превратится в /me с анимацией.

## Ролевые команды

| Команда | Описание |
|---------|----------|
| `/me <действие>` | Описание действия персонажа |
| `/do <описание>` | Описание обстановки или «закадровый» комментарий |
| `/try <действие>` | Действие со случайным исходом: сервер сам припишет «(удачно)» или «(неудачно)» |
| `/todo действие*реплика` | Действие с одновременной репликой, разделитель — `*` |
| `/toss` | Подбросить монетку ($1): выпадает орёл или решка |

Примеры:

```
/me медленно достаёт сигарету и закуривает
/do В воздухе пахнет дождём, асфальт мокрый
/try взломать замок
/todo протягивает руку*Добро пожаловать
```

## Взаимодействия с игроками

Подойди к другому игроку (обычно в радиусе 5 метров) и открой меню: `/interactions` либо `/interactions <id>`.

| Команда | Действие |
|---------|----------|
| `/interactions [id]` | Меню всех взаимодействий с ближайшим игроком |
| `/id <id>` | Короткая справка об игроке (ник, пинг, клиент) |
| `/ids <имя или id>` | Поиск игрока по части ника или по ID |
| `/hi <id>` | Предложить рукопожатие |
| `/kiss <id>` | Поцеловать |
| `/minet <id>` | Интим-взаимодействие (18+) |
| `/flowers <id>` | Подарить цветы (нужно держать их в руках — `/takeflowers`) |
| `/pass <id>` | Показать ID-карту (нужна в инвентаре) |
| `/showlic <id>` | Показать свои лицензии |
| `/lic` | Посмотреть список своих лицензий |
| `/pay <id> <сумма>` | Передать наличные |

Все парные взаимодействия требуют подтверждения от второго игрока.

## Объявления

```
/ad <текст>
```

Платное объявление в общий канал рекламы (максимум 80 символов, цена пропорциональна длине). Сотрудники SAN News публикуют бесплатно. Объявление попадает в очередь модерации.

---

## Анимации, внешность и смайлы

| Команда | Описание |
|---------|----------|
| `/anim [категория] [индекс]` | Меню анимаций или прямой выбор по индексу |
| `/awalk <стиль>` | Сменить стиль ходьбы |
| `/animindex` | Показать текущий индекс проигрываемой анимации |
| `/smileinfo` | Справочник текстовых смайлов |

---

## Жалобы

```
/report <id> <причина>
```

Отправляет жалобу на конкретного игрока администраторам онлайн. Есть ограничение на частоту отправки (анти-флуд).
