# Мир и локации

## NPC

По всему миру расставлены неигровые персонажи (NPC). Подойдите к NPC — начнётся диалог. Камера повернётся к персонажу, над ним появится текст реплики, вы выбираете ответы из меню.

Диалог прерывается, если вы отойдёте или начнёте другое действие.

## Магазины и точки обслуживания

Все магазины и точки сервиса можно найти через GPS (`/gps`).

### Супермаркеты и фастфуд

Покупка еды и напитков для восполнения сытости. Оплата наличными.

### АЗС (заправочные станции)

```
/fill
```

Команда доступна, когда вы за рулём и стоите у колонки.

- Стоимость: **$1 за литр**
- Максимум топлива в баке: **300 литров**
- Время заправки зависит от объёма (несколько секунд)
- При заправке 50+ литров засчитывается ежедневное задание «Пустой бак»

На спидометре топливо отображается: жёлтым если >30 л, красным если ≤30 л.

### Вендинговые автоматы

Быстрая покупка еды и напитков — без входа в магазин. Подойдите к автомату и взаимодействуйте с ним.

## Спидометр (HUD в транспорте)

Пока вы за рулём (не на велосипеде), в правом нижнем углу отображается:

| Показатель | Описание |
|-----------|---------|
| Скорость | В KM/H |
| Fuel | Жёлтый >30 л / Красный ≤30 л |
| HP | Здоровье авто, красным при ≤30% |
| ENGINE | ON (зелёный) / OFF (красный) |
| LOCK / UNLOCK | Двери закрыты / открыты |
| MAX | Ограничитель скорости: зелёный — выкл., красный — вкл. |

## Сбор грибов

По всей карте в 41 зоне появляются дикорастущие грибы. Находите их, заходите в пикап — начнётся анимация сбора (~3.5 секунды). Гриб попадает в инвентарь.

Грибы можно продать или использовать (особый эффект).

Зоны сбора — в основном загородные районы, леса и поля.

## Интерьеры

Многие здания имеют собственные интерьеры — зайти можно через пикап у входа. Выйти — через пикап внутри.

Интерьеры есть у:
- Всех церквей
- Полицейских участков
- Больниц
- Банков и правительственных зданий
- Бизнесов (магазины, бары, клубы)
- Домов (при наличии)
- Автошколы, ФБР, университета и других организаций

## Карта быстрых маршрутов (GPS)

```
/gps
/house [id]
```

`/gps` открывает меню по категориям, `/house` ставит точку на дом по номеру.

Категории в меню GPS:

| Категория | Что включает |
|-----------|-------------|
| Известные места | Welcome Motel, МФЦ, склады боеприпасов SF и LV |
| Базы организаций | Правительство, ФБР, NDDI (автошкола), Центробанк, университет, SAN News, ВМС |
| Опасный район | Чёрный рынок, базы банд Aztec / Rifa / Grove / Ballas / Vagos |
| Больницы | Все больницы на карте |
| Полицейские участки | Все отделения |
| Аренда транспорта | Все пункты проката |
| Продукты для бизнеса | Торговые порты LS и SF |
| Церкви | Все церкви |
| Частные фермы | Точки фермеров |
| Поиск дома | Ввод ID дома (`/house`) |
