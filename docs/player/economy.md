# Деньги и работа

## Деньги

В игре два «кошелька»:

- **Наличные** — деньги при себе. Видны в `/stats`. Можно потерять при смерти в некоторых ситуациях.
- **Банковские счета** — деньги в банке. Безопасны, доступны через ATM или в отделении.

## Банк и ATM

В банке (по меткам на карте) или возле любого ATM доступно меню управления счетами: `/bank` либо
обычный пикап банкомата. У тебя может быть несколько счетов одновременно; один из них помечен
как **основной** — именно на него идут входящие переводы по имени. Создать новый счёт можно только
находясь в отделении банка.

Для каждого счёта доступно:

- Пополнение наличными / снятие наличных
- Перевод по **номеру счёта** — нужен точный номер получателя
- Перевод по **имени персонажа** — деньги уйдут на основной счёт получателя
- Смена основного счёта

Быстрые команды (работают только в банке или у ATM):

```
/bank                           — меню всех твоих счетов
/bankaccount <номер>            — меню конкретного счёта
/transfer <номер>               — перевод с этого счёта по номеру
/transfername <номер>           — перевод с этого счёта по имени игрока
```

## Передача наличных

Передать наличные другому игроку рядом:

```
/pay <игрок> <сумма>
```

## Объявления

Подать городское объявление через `/ad <текст>`. Цена — по $1 за символ; для сотрудников SAN News
бесплатно. Лимит длины 80 символов, одно сообщение раз в 5 секунд, в очереди на трансляцию держится
не более 30 объявлений одновременно.

## Работа

### Как устроиться

Работы находятся в определённых точках города — ищи через GPS: `/gps` → «Работы» покажет все места
найма с расстоянием до каждого, выбранное место ляжет меткой на карту. Для транспортных работ
нужны соответствующие права: без них просто не получится сесть за руль рабочего транспорта.

Уволиться: `/quitjob` (или через `/mm` → «Завершить работу»).

### Доступные профессии

| Профессия | Требования | Особенности |
|-----------|-----------|-------------|
| Курьер | — | Доставка посылок по городу на велосипеде, выбор из активных маршрутов |
| Водитель автобуса | Водительские права | Маршруты по LS / SF / LV, оплата за круг |
| Водитель трамвая | Водительские права | Маршрут по San Fierro, фикс. оплата за круг |
| Машинист поезда | Водительские права | Межгородской маршрут, фикс. оплата |
| Водитель мусоровоза | Водительские права | Сбор отходов по точкам |
| [Лесоруб](industry.md#лесопилка-angel-pine) | — | Заготовка древесины на лесопилке Angel Pine, оплату назначает владелец. [Без прав](industry.md#без-водительских-прав) технику водят только на территории |
| [Шахтёр](industry.md#карьер-hunter-quarry) | — | Добыча руды в карьере Hunter Quarry — на уступах и в шахте, оплату назначает владелец. [Без прав](industry.md#без-водительских-прав) технику водят только на территории |
| [Работа на ферме](industry.md#зерновая-ферма-central-farm) | — | Central Farm: тракторист, комбайнёр, уборка тюков или пешая работа в теплицах, оплату назначает владелец. [Без прав](industry.md#без-водительских-прав) технику водят только в угодьях |

Чем выше рабочий навык (`/skills`), тем выше зарплата (до +15% к базовой ставке). Каждое завершение
круга курьером/автобусником/машинистом/таксистом также двигает котировки соответствующих
компаний на бирже (см. [Биржа](stocks.md)).

> Отдельной профессии «таксист» нет. Для перевозки пассажиров можно арендовать такси
> (нужна **лицензия на такси**) в таксопарке — см. раздел «Аренда транспорта».

## Магазины

По городу расположены магазины разных типов:

| Тип | Что продаёт |
|-----|------------|
| Супермаркет (24/7, Supa Save и т.п.) | Еда, напитки, мелочёвка |
| Cluckin' Bell / Burger Shot / Well Stacked Pizza | Фастфуд |
| Бары и стрип-клубы (Alhambra, обычные, Liberty, Jizzy, The Pig Pen) | Алкоголь |
| Ammu-Nation | Оружие (при наличии лицензии) |
| Магазины одежды (Didier Sachs, ProLaps, ZIP, Sub Urban, Victim, Binco) | Одежда и аксессуары |
| Вендинговые автоматы (Sprunk, хотдоги, лапша) | Быстрые перекусы, напитки |
| Секс-шопы (Adamson's) | Тематические товары |
| Фермерские точки | Сельхозпродукция, инвентарь |

Каждая покупка в брендовом магазине учитывается драйвером цены соответствующей компании на бирже.

## Биржа и акции

Полноценный способ заработка — торговля акциями ~100 публичных компаний штата. Команды:
`/stocks`, `/portfolio`, `/stock <тикер>`, либо `/mm` → **Биржа** / **Портфель акций**.

Подробнее — в разделе [Биржа и акции](stocks.md).

## Торговые порты

Торговые порты (Los Santos и San Fierro) — место, где владельцы бизнесов закупают товары для
своих точек. Найти: `/gps` → «Торговые порты».

Товары оплачиваются **со счёта бизнеса**, а не из личного кошелька: приехать за ними может как
владелец, так и его [доверенное лицо](property.md#доверенные-лица). За каждый потраченный доллар
бизнес получает 2 единицы товара, максимум $2500 за один заезд. Гружёный Mule нужно довезти до
самого бизнеса — маршрут ставится автоматически.

Рядом с портами работают **экспортные терминалы** — туда владельцы промышленных предприятий
сдают добытое сырьё, см. [Промышленные предприятия](industry.md#экспорт-сырья).

## Ресурсы и промыслы

Часть бизнесов — не магазины, а предприятия по добыче сырья со своим складом и наёмными
работниками: лесопилка Angel Pine, карьер Hunter Quarry и зерновая ферма Central Farm. Устроиться
туда можно без всяких разрешений: рабочий транспорт выдают на месте, платит владелец предприятия.

Целиком — в разделе [Промышленные предприятия и ресурсы](industry.md).

## Фермерство

На картах с фермами можно арендовать участок и выращивать культуры: инвентарь (лопата, ведро)
и процесс включают команды `/plant` и `/fertilize`. Список ферм и свободных участков —
команда `/farm`.

## Грибы

По всей карте в 41 зоне растут дикие грибы — загородные районы, леса, поля. Подойди вплотную —
начнётся сбор (~3.5 секунды). Собранный гриб попадает в инвентарь. В каждой зоне держится до
10 грибов одновременно; новые постепенно респавнятся со временем.

## Заправка транспорта

```
/fill
```

Подъедь к колонке на АЗС, сядь за руль и вызови команду. В диалоге выбери количество литров.

- Цена: **$1 за литр**
- Ёмкость бака: до **300 литров**
- Заправка 50+ литров засчитывается в ежедневное задание
- Если у АЗС есть владелец — доступен только запас на складе этой станции

Найти АЗС: `/gps` → магазины / АЗС. Проданные литры топлива идут в драйвер цен FOIL/XMER на бирже.
