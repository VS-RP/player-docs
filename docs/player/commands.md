# Команды игрока

## Основные

| Команда | Описание |
|---------|----------|
| `/mm`, `/menu`, `/help` | Главное меню |
| `/cmds` | Список базовых команд |
| `/id <игрок>` | Информация об игроке |
| `/ids <имя или ID>` | Поиск игрока по имени или ID |
| `/stats` | Характеристики персонажа |
| `/skills` | Навыки (оружейные и рабочие) |
| `/lic` | Ваши лицензии и документы |
| `/pass <игрок>` | Показать ID-карту ближайшему игроку |
| `/showlic <игрок>` | Показать лицензии ближайшему игроку |
| `/time` | Текущее игровое время и зона |
| `/zone` | Название текущей зоны |
| `/spawnchange` | Вызвать меню выбора места появления на следующем входе |

## Чат и ролевая игра

| Команда | Описание |
|---------|----------|
| `/me <действие>` | Описание действия персонажа |
| `/do <текст>` | Описание окружающей обстановки |
| `/s <текст>` | Крик (слышен в радиусе ~60 м) |
| `/b <текст>` | Внеигровой чат (OOC) |
| `/todo <действие>*<реплика>` | Действие с произносимой репликой |
| `/try <действие>` | Попытка со случайным исходом (удача/неудача) |
| `/tl <текст>` | Транслитерация (латиница → кириллица) |
| `/smileinfo` | Справочник смайлов/эмоций и сокращений |
| `/ask <вопрос>` | Задать вопрос администрации |
| `/report <игрок> <причина>` | Жалоба на игрока |

## Взаимодействия с игроками

| Команда | Описание |
|---------|----------|
| `/interactions` | Меню взаимодействий с ближайшим игроком |

| `/takeflowers` | Взять цветы из инвентаря в руки |
| `/pay <игрок> <сумма>` | Передать наличные |

| Команда | Описание |
|---------|----------|
| `/v` | Меню управления транспортом за рулём |

| `/lock` | Закрыть/открыть двери (за рулём или рядом со своим авто) |
| `/trunk` | Открыть/закрыть багажник |
| `/bonnet` | Открыть/закрыть капот |
| `/lsp <км/ч>` | Установить лимит скорости (0 — сбросить) |

| `/fill` | Заправиться на заправке |
| `/loadcar <индекс>` | Вызвать личный автомобиль на ближайшую парковку |
| `/unloadcar <индекс>` | Убрать личный автомобиль |
| `/carmenu <индекс>` | Меню управления личным автомобилем |
| `/fixcar <индекс>` | Зареспавнить личный автомобиль |

## Фракционные команды

> Доступны только членам соответствующей организации. Подробнее — в разделе [Фракции](fractions.md).

### Общие для всех фракций

| Команда | Описание |
|---------|----------|
| `/f <сообщение>` | Рация/чат фракции |
| `/fhelp` | Меню команд фракции |
| `/members` | Участники фракции онлайн |
| `/offmembers` | Участники фракции офлайн |
| `/fbalance` | Баланс банка фракции (по праву) |
| `/fputbank <сумма>` | Внести деньги в банк фракции |
| `/fwithdraw <сумма>` | Снять деньги из банка фракции |
| `/fput <слот> [кол-во]` | Положить предмет на склад фракции |
| `/unload` | Разгрузиться боеприпасами на складе |

### Руководство

| Команда | Описание |
|---------|----------|
| `/invite <игрок>` | Пригласить во фракцию |
| `/uninvite <игрок> <причина>` | Уволить из фракции |
| `/giverank <игрок> [ранг]` | Выдать/изменить ранг |
| `/fpanel` | Панель лидера фракции |
| `/ffixcar [id]` | Заспавнить фракционный транспорт |
