# Фракции

Фракции — это организации, в которые объединяются игроки. У каждой своя роль в жизни сервера, своя иерархия рангов и особые возможности. Вступить во фракцию можно только по приглашению руководства — подойди к лидеру нужной организации в игре.

## Государственные структуры

### SAPD — полиция
Ловит преступников, патрулирует, управляет тюремной системой. Форма обязательна.

| Команда | Что делает |
|---------|-----------|
| `/cuff <игрок>` | Надеть наручники |
| `/uncuff <игрок>` | Снять наручники |
| `/tazer <игрок>` | Применить тазер |
| `/atazer <игрок>` | Тазер из авто |
| `/follow <игрок>` | Вести задержанного за собой |

Есть склад оружия и пункт переодевания.

### FBI
Федералы. Работают по тяжким делам и ведут оперативную работу.

### Медики
Скорая помощь и больницы. Лечат, реанимируют, отвозят с места ранения в госпиталь. Ранги от «Санитар» до «Глав. врач».

### Правительство
Управление штатом: лицензии, недвижимость, госзакупки.

| Команда | Описание |
|---------|---------|
| `/gov <текст>` | Правительственное объявление |
| `/dep <текст>` | Объявление департамента |

### Центральный банк
Обслуживает игроков и фракции.

| Команда | Описание |
|---------|---------|
| `/bank` | Меню банка |
| `/bankaccount <игрок>` | Посмотреть счёт игрока |
| `/transfer <ID> <сумма>` | Перевод по ID |
| `/transfername <имя> <сумма>` | Перевод по имени |

### Автошкола (NDDI)
Уроки вождения и продажа лицензий.

| Команда | Описание |
|---------|---------|
| `/lesson` | Начать / завершить урок |
| `/lic` | Посмотреть свои лицензии |
| `/showlic <игрок>` | Показать свои лицензии игроку |
| `/givelic <игрок> [id]` | Продать лицензию (для сотрудников) |
| `/agivelic <игрок>` | Административная выдача |

### Университет
Даёт профессии и повышает навыки персонажей. Ранги от «Стажёр кафедры» до «Ректор».

### San News
СМИ сервера: новости, прямые эфиры, модерация объявлений.

| Команда | Описание |
|---------|---------|
| `/n <текст>` | Выпуск новостей |
| `/live` | Настройки стрима |
| `/golive` | Включить прямой эфир |
| `/ad <текст>` | Подать платное объявление (доступно всем) |
| `/adcheck` | Проверить свои объявления (всем) |
| `/adedit <id>` | Редактировать |
| `/adcancel <id>` | Отменить |
| `/adaccept <id>` | Одобрить публикацию |
| `/fad <текст>` | Бесплатное фракционное объявление |

### Армия (СВ / ВМС)
Сухопутные войска в Las Venturas и Военно-морские силы в San Fierro. Охраняют военные зоны, имеют доступ к тяжёлой технике.

## Уличные банды

Пять банд делят карту на цветные зоны и ведут войну за контроль. Чем больше зон — тем больше дохода.

| Банда | Цвет |
|-------|------|
| Grove Street | Зелёный |
| Ballas | Фиолетовый |
| Vagos | Жёлтый |
| Rifa | Голубой |
| Aztec | Бирюзовый |

### Захват зон

| Команда | Описание |
|---------|---------|
| `/gangs` | Карта зон и текущий контроль |
| `/capture` | Начать захват зоны, стоя на ней |
| `/captures` | Список активных захватов |
| `/extendcapture` | Продлить захват |
| `/endcapture` | Досрочно завершить захват |
| `/gzc` / `/gzcolor` | Цвета зон на миникарте |

### Чёрный рынок и ограбления материалов
Банды пополняют склады оружия через ограбления точек на карте. Запуск — через интерфейс чёрного рынка лидера банды. Во время ограбления по игроку будут вызваны копы — будь готов отстреливаться.

## Общие команды фракций

Доступны всем членам любой фракции.

| Команда | Описание |
|---------|---------|
| `/f <текст>` | Связь по рации |
| `/fhelp` | Подсказки по командам фракции |
| `/members` | Онлайн-участники |
| `/offmembers` | Офлайн-участники |
| `/fbalance` | Баланс фракционного банка |
| `/fputbank <сумма>` | Внести в банк фракции |
| `/fwithdraw <сумма>` | Снять из банка фракции |
| `/ffixcar` | Починить фракционное авто на гаражной точке |

## Команды руководства

| Команда | Кому | Описание |
|---------|------|---------|
| `/invite <игрок>` | Боссам | Пригласить во фракцию |
| `/uninvite <игрок>` | Боссам | Исключить |
| `/giverank <игрок> <ранг>` | Боссам | Изменить ранг |
| `/fpanel` | Лидерам | Панель управления фракцией |

---

## Вступление

Вступить можно только по приглашению от босса или лидера. Зайди в штаб-квартиру нужной организации и найди руководство в игре. Часть фракций требует собеседования или испытательного срока.
